# SC2001 Project 1

Integration of Merge Sort & Insertion Sort

## Project Overview

This project implements and analyses a hybrid sorting algorithm that combines Merge Sort and Insertion Sort.

The hybrid algorithm uses Merge Sort for larger subarrays and switches to Insertion Sort when the subarray size is less than or equal to a threshold value `S`.
